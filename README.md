# 🧲 MagnaSync

### Dashboard de Monitoramento de Ressonância Magnética

O **MagnaSync** é uma aplicação web desenvolvida para **visualizar e acompanhar dados de monitoramento de equipamentos de ressonância magnética**.

A plataforma apresenta informações de desempenho por meio de **dashboards e indicadores**, permitindo identificar alterações nos recursos monitorados e acompanhar possíveis alertas.

## Funcionalidades

* Dashboard com indicadores de monitoramento
* Visualização de CPU, RAM e armazenamento
* Exibição de alertas e ocorrências
* Histórico dos dados coletados
* Visualização do status dos equipamentos
* Consulta das informações de monitoramento

## Tecnologias

* Java
* Python
* HTML / CSS / JavaScript
* Banco de Dados
* Git / GitHub

## Objetivo

Disponibilizar uma interface centralizada para **visualizar, acompanhar e analisar os dados dos equipamentos**, auxiliando na identificação de possíveis problemas antes que causem indisponibilidade.
